# Rana Academy Shimla — Premium Static Rebuild

GitHub Pages-ready static website rebuilt from the academy's existing public content structure.

## Files
- `index.html` — conversion-focused homepage
- `resources.html` — organised study resource library
- `achievements.html` — student result archive
- `contact.html` — WhatsApp-based enquiry flow
- `assets/css/style.css` — full responsive design system
- `assets/js/main.js` — mobile menu, filters, modal, WhatsApp form, reveal effects
- `robots.txt` + `sitemap.xml` — basic SEO
- `404.html` — custom not-found page

## GitHub Pages
1. Create/open a GitHub repository.
2. Upload all files and folders from this ZIP to the repository root.
3. Go to **Settings → Pages**.
4. Set **Deploy from a branch** → `main` → `/ (root)`.
5. Save. GitHub will provide the live URL.
6. If using `ranaacademyshimla.com`, connect the custom domain in GitHub Pages and DNS, then keep the sitemap URLs as they are.
